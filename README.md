# Python_Diwali_Sales_Analysis
# 🪔 Diwali Sales Analysis using Python

## 📌 Project Overview

This project focuses on analyzing Diwali sales data using Python to uncover customer purchasing behavior, sales trends, and business insights. The analysis helps identify high-performing customer segments, states, occupations, and product categories during the festive season.

The project includes:

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization
* Business Insights

---

# 📂 Dataset Information

The dataset contains customer purchasing information such as:

* Customer Gender
* Age Group
* State
* Marital Status
* Occupation
* Product Categories
* Orders
* Sales Amount

# 🔍 Key Insights

Some important findings from the analysis:

✅ Female customers contributed more to sales compared to male customers.

✅ Customers aged between 26–35 years made the highest purchases.

✅ Married women were one of the major buyers during Diwali sales.

✅ Certain states generated significantly higher revenue.

✅ IT, Healthcare, and Aviation professionals showed higher purchasing power.
